Sohayb Hassan is a full-stack engineer with six years at Capgemini (Turin, Italy) building backend and web systems for banks, insurers and corporate clients. He currently delivers features end to end on a retail bank's mobile platform: Java 17 / Spring Boot 3 microservices, an OpenAPI-first BFF layer on JDK 21 and the React Native app. He is at home with the unglamorous side of banking integration (legacy hosts, BPM processes, multi-environment release pipelines) and with the tooling that keeps a large multi-repository programme moving. He started out migrating COBOL to Spring Boot; he now spends personal time on LLM-assisted modernisation tooling where the output is verified, not trusted.
