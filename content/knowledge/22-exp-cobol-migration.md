As an intern at Capgemini (10/2020 – 01/2021, insurance client) he migrated a legacy COBOL policy-listing system to Java Spring Boot services (Hibernate/JDBC on PostgreSQL) consumed by an Angular.js front end, and kept the Maven CI running for the team. This hands-on COBOL → Java migration is the root of his current personal project on LLM-assisted modernisation.
