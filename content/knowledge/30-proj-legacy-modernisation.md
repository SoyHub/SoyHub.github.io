Personal project, in progress: LLM-assisted legacy modernisation — COBOL to Spring Boot with differential-execution verification of the generated code. The design principle is that the referee comes before the agent: a differ that runs the original and the generated code on the same inputs and proves equivalence is built first, and generated code is trusted only through it. Stack: Python, Java 17 / Spring Boot 3, the Claude API, tool-calling agents, an evaluation harness. No public link yet; it will be linked from /projects when it is. Measured results are not published until they exist.
