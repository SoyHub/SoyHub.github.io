The site is an API explorer: pick an endpoint on the left (or press `/`, use ↑↓ and Enter), press Send, read the 200 response. Every endpoint is a real page with its own URL, so links can be shared. Each response has a Rendered tab and a JSON tab. POST /hire opens a pre-filled email; POST /ask is this console. From a terminal, `curl` on /cv.txt returns the CV as text and /cv.json returns a JSON Resume.
